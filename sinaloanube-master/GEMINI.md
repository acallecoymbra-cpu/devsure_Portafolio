# Graphify primero

Antes de analizar este proyecto, sigue la regla de `AGENTS.md`:
lee `docs/GRAPHIFY.md` y `graphify-out/GRAPH_REPORT.md`, consulta el grafo
con `graphify query` y verifica después los archivos fuente pertinentes.
Si cambió el código, regenera el grafo según `docs/GRAPHIFY.md`.
No instales dependencias de Laravel para realizar análisis estático.
